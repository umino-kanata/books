# マイコレクション Ver.2.2

GitHub Pagesで動くスマホ向けコレクション整理アプリのプロトタイプです。

## Ver.2.2 主な変更
- トップ画面を「本 / CD / 映像 / マイコレクション」に整理（本以外は開発中表示）
- 本の種類を「書籍 / 雑誌 / コミック」に整理
- 著者・訳者・写真・編者・監修などを行追加式で登録
- 所有と貸出中を並べて表示
- カテゴリーの名称変更・並び替え・非表示・削除
- 保管場所の登録・選択・名称変更
- 「＋」ボタンを「＋ 登録」に変更
- ISBN検索で書籍情報を自動入力
- スマホのカメラ/画像からISBNバーコード読み取り
- Ver.1のローカルデータ・カテゴリーをできるだけ引き継ぐ
- バックアップ形式をVer.2.2へ更新

## GitHubへの更新
`index.html`、`style.css`、`app.js`、`README.md` の4ファイルを既存の `books` リポジトリへ上書きしてください。

GitHub Pagesは `main` ブランチの `/ (root)` のままでOKです。


## Ver.2.2 変更
- トップ画面右下に「📷 ISBN読取」を追加
- 「＋ 登録」は手入力、新しい「ISBN読取」はカメラ登録の入口として分離
- カテゴリー管理はトップ画面の「編集」から利用


## Ver.2.2
- ISBN読取は背面カメラを優先して自動起動
- 英語のカメラ選択UIを表示せず、日本語の案内と読取枠だけを表示
- 背面カメラ指定に失敗した場合も、利用可能なカメラから背面候補を自動選択
