# マイコレクション Ver.2.4

GitHub Pagesで動く、本・コレクション管理アプリのプロトタイプです。

## Ver.2.4 の主な変更

- 保存前に別のISBNを読み取ると確認を表示し、情報混在を防止
- 新規保存後に「次のISBNを読む」を選べる連続登録導線
- 連続登録時は直前の保管場所を引き継ぐ
- コミックに「所有巻」欄を追加（例：`1-11,13`）
- 国立国会図書館サーチの著者名から生年・読み仮名重複を整理
- ISBNなし本向けに「奥付を撮る（β）」入口を追加
  - 現段階では写真を画面で確認しながら手入力
  - 写真そのものは保存しない
- 保存済み作品は一覧のタイトルをタップして編集可能

## ISBN検索

Google Books → Open Library → 国立国会図書館サーチの順に検索します。
13桁ISBNで見つからない場合はISBN-10も試します。

## バックアップ

バックアップファイルを端末へ保存できます。端末故障・機種変更に備え、Google Driveなどにもコピーしてください。
